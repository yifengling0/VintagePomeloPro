# Deck 动画与 DroidDeck 源码对照

> 本文记录 v114 的历史动画对照与验证。后续 v115 已精简入口并把动画开关移入系统设置；旧三标签面板不是当前导航，参见 `DECK_NAVIGATION.zh-CN.md`。

2026-10-20。参考 Droid-Deck/DroidDeck 固定提交 `6bbcf3ad8be8ef1b80a97bf5f3444e4e001749b9`。本轮工程基准 `e5c43c4a`，分支 `main_proton_steamarm64`，候选 `native-steam-external-v114`。对照 Kotlin/Compose 源码，在 ArkUI 中重建动效，不引入 Android 运行时。

## 确认的差异与修改

| 区域 | 原实现的问题 | 本轮处理与参考 |
| --- | --- | --- |
| 通用曲线 | 多数使用系统 EaseOut，与上游节奏不同 | `Motion.Ease` 的 cubic-bezier(0.2,0.8,0.2,1)；物理弹簧按单位质量把 Compose 阻尼比换成系数 `2ζ√k`，用 ArkUI interpolatingSpring 保持自然收敛 |
| 设置面板 | 整块滑动，背景、内容同一节奏 | 参考 `LiftSheet.kt`，先下拉 24vp、背景缩小 5% 并淡出文字；120ms 后弹簧上抬；380ms 后内容以 55ms 间隔、220ms 时长依次显示 |
| 面板关闭 | 固定 310ms 删除面板，不能匹配弹簧终点 | 内容先在 90ms 内淡出，面板延后 60ms 用临界阻尼收回，物理动画完成才移除遮罩；代次校验与有限定时器防止旧回调干扰重开 |
| 标签切换 | 直接替换内容 | 参考上游 240ms 淡入淡出与正反向 24vp 位移；动画开关文案在保留的标签节点内读取实时状态，避免值参数停留在旧文字 |
| 主屏导航 | 把 entered=true 再设一次，实际没有动画 | 页面有实际插入/移除转场，240ms 淡入淡出和小幅位移；首次入场延后首帧，450ms 淡入抬升 |
| 按钮与游戏卡片 | 卡片只放大到 1.025，缺少按压反馈 | 参考 `FrontEndWidgets.kt` / `FrontEndArt.kt`：按钮按下 0.955、侧栏 0.95；卡片按下 0.97，聚焦/悬停 1.04、上抬 5vp，缩放锚点在高度 90%；颜色/阴影与缩放分别使用补间/弹簧 |
| 扇形封面 | 漂浮曲线不同，打开面板会重置位置 | 使用上游 FastOutSlowIn 曲线和 9/11/13 秒往复；面板打开时保持合成动画连续运行，避免封面跳回起点 |
| 封面墙 | 固定列数、6 张为周期，移动距离不随可用高度适配 | 按上游倾斜后的视域计算列数和重复段，112×168vp、间隙 14vp、倾斜 -13°、40 秒循环；相邻列反向，重复双段保证循环接缝；仍由系统合成动画驱动 |

源代码落点：`DeckMotion.ets`、`DeckHome.ets`、`DeckBackdrop.ets`。退出 Deck 清除待执行阶段；关闭动画将面板立即收敛到目标状态，不运行物理弹簧。面板仍可通过关闭按钮、遮罩、向下手势与返回键关闭。

## 验证

- ArkTS 编译、签名、USB MLR-AL10 覆盖安装通过。候选内三个动画文件的 SHA-256 均与工作区一致；EntryAbility 固定既有 baseline。未操作手机。
- 既有 Deck 自动回归通过：布局、Linux 清单、CEF 恢复、窗口任务与会话命令。
- 设备 18 项检查通过：面板开合，三个标签，动画开关即时文案与静态开合，关闭期间进入组件页及返回，弹簧关闭后无残留遮罩，游戏库/工具/运行中切换，经典界面往返。
- 保存 6 张面板开/关过程的有界截图及合成图，看到中间位置、内容入场和最终恢复；截图命令有时间区间，不能当成逐帧视频、精确时长或帧率验收。未运行 DroidDeck Android 包进行并排录屏。
- 当前真实 Steam 库只有两款游戏，实机覆盖扇形背景；四款以上封面墙只完成源码对照和编译，尚未实机验收。实体鼠标悬停、手柄聚焦的视觉效果仍需人工感受确认。
- 未启动游戏或修改存档；Wine、GNU runtime、Steam 启动协议和所有子模块指针不变。Mesa 仍为 `557fa3e781ea6e78fcff3ee759c25f60c3055064`。

## 与上游仍有差异

主按钮跟随面板抬升、发光边缘及折叠回按钮的共享形变尚未复刻；面板保留本应用现有标题、宽度和入口组织。向下拖动仍是达到阈值后关闭，没有实现上游按拖动进度连续跟手的 LiftSheet。卡片扫光和滑动焦点边框也未复刻。故本轮对齐了主要参数与交互时序，不能称为逐像素或全部动效一致。

签名 HAP SHA-256：`b59c0b90673d436255f82bdba8653c00d378ed0814030c3092b9b0d0176b1693`。本机证据：`deck-motion-v114-checks.local.json`、`deck-motion-timeline.private.jpg`，原始画面仅本机保存。保留 v114 当前包与 v112 稳定回退包，删除 v113 中间包及 unsigned 包。本轮源码尚未提交。
