# 剪贴板快捷菜单

基于 `feature/gamescope-port@e5884403`，把宿主键盘打开时左上角常驻的复制、粘贴按钮
收进原有输入快捷栏。快捷栏新增剪贴板图标，点击后在附近打开深色菜单，无须先唤起键盘。
游戏及 Wine 原有右键菜单保持原行为。

- 菜单提供“复制选中文字”，只向当前 Wine 窗口发送完整 Ctrl+C。
- 只有系统剪贴板含文本类型时才显示“粘贴”；检查中、空剪贴板及非文本各有状态提示。
  菜单打开只查询元数据，不读取、预览或保存剪贴板正文。
- 粘贴沿用真实鸿蒙 `PasteButton` 和原有正文读取流程，保留未授予长期读取权限时的
  点击临时授权。安全组件位于快捷栏手工事件分发之外，不模拟点击授权。
- 点击菜单外或 Escape/返回关闭；切会话、隐藏及页面销毁时关闭并释放输入捕获。
  异步检查不能重新打开已关闭菜单；读取期间切换窗口或会话后不发送 Ctrl+V。
- 横纵工具栏的尺寸与命中范围同步更新，菜单限制在当前画面内。

`make test-game-mode-models` 已通过。新增行为判据覆盖文本可用性、不预读/申请权限、
关闭后迟到结果、输入捕获释放、复制粘贴目标隔离，以及手机/平板横纵工具栏边界。
原剪贴板授权/拒绝、临时授权、中文双向同步、有界读取与会话生命周期判据继续通过。

本轮没有操作设备。菜单外观、真实点击临时授权、手机键盘布局与复制粘贴仍须真机确认；
