# 旧柚 Pro 2.1.0

- 统一 Wine 图形选项。DXVK 1.10 和 2.6 均包含 D3D9 支持。DXVK 2.6 可启动兼容的 DX12 游戏，支持直通的设备优先使用直通，其余走 Venus。
- 在满足 Vulkan 1.3 等运行条件的设备上，MobileGL 可为 32 位和 64 位应用提供 OpenGL 4.6。兼容性优先的设备沿用原有 OpenGL 路径。
- 相对鼠标输入按游戏画面宽度调整，改善高分辨率下的跟随速度。
- PC 的 Wine 虚拟桌面在虚拟输入栏中增加全屏切换。
- 改善从游戏卡片启动 Steam 时的窗口等待，以及返回已打开的 Steam 窗口。Steam 继续使用旧版离线导入包。
