# 1.5.3 用户测试版

- 版本：1.5.3（1005030），ARM64，Release 构建，未签名 HAP。
- 保存 Linux FEX 兼容层、Edge PC 窗口/中文输入，以及原 OHOS Wine 的 FEX/Box64 选择等当前工作。
- 本测试包沿用校验固定的 Steam/GNU Proton 组件和当前平板基线图形驱动；实验 NativeBuffer/Venus 构建使用独立诊断入口，不替换正式包驱动。
- 已有 Steam 离线组件包仍按原格式使用。本次未要求更新 Steam 或重下游戏库。

## 建议测试

请区分游戏使用的是“原生 Linux”还是“Windows + GNU Proton”，并记录 Steam AppID 和所选兼容工具。原生 Linux 游戏还需记录实际架构；ARM64 Steam 客户端并不代表游戏本身是 ARM64。

1. 冷启动 Steam，以及退出后再次启动；检查普通窗口与大屏模式切换。
2. 游戏首次启动和再次启动，检查画面、声音、鼠标/双指滚动、键盘与手柄。
3. 持续运行 10 分钟后正常退出，再次启动。涉及云存档时保留原存档，先验证正常退出同步。
4. 启动失败、黄屏、黑屏或崩溃时，记录发生时间并导出应用日志；请同时说明机型、系统版本和是否处于 PC 模式。

## 已知限制

Banana 已出现正常画面，但长时间运行仍发生 SIGSEGV，尚未完成稳定性验收。此版本供继续收集兼容性反馈，不代表全部原生 Linux 游戏或完整 SteamOS 已兼容。

## 本次构建核验范围

Release 编译、完整主机模型回归、GNU 组件源码/包体清单和 Wine 载荷检查通过；全部 Native 库与现用 1.5.2 depot 平板基线逐项比对。此次没有新增设备验收。

冻结的 1.4.9 核心库发布锁，以及旧图形补丁登记锁仍拒绝当前基线（包含此前已存在的库/源码差异）。没有改写这些锁来制造正式发布验收通过，相关结果随测试包保存。此包用于兼容性测试，不作为已通过全部图形发布门槛的正式版本。
