## 规则和验证范围

普通取消续费是 `autoRenew=0`；官方 `status=1` 且付费有效期未结束，仍应保留 VIP。官方 `status=5` 是撤销，即使旧记录有未来到期日期也不再提供权益。此前后端自动测试已覆盖普通取消续费、重启重新验单和严格到期，本轮未取消新订阅、未退款，因此普通取消续费未到期的真机场景仍未验证。旧撤销记录的具体原因没有取得官方证明，不能归因于退款、未确认或沙盒自动结束。

当前备份只覆盖已实现的全局白名单设置和完整输入方案；每游戏 AppSettings、游戏与方案绑定及其他全局参数尚未统一纳入配置快照。当前验证不证明全部应用沙盒配置都能恢复，也不包含此前已撤下的游戏存档备份。
