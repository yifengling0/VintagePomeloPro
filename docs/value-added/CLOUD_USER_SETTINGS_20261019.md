# 云端仅备份用户配置（2026-10-19）

按用户要求，云端备份范围收窄为系统/外观/输入设置及输入方案。游戏库目录、游戏配置索引、最近运行、游玩时长、壁纸文件、字体文件和资源登记不再上传。本地完整备份与游戏目录配置继续用于本机恢复。

## 实现

- 新增云端配置投影，单份只含一个 `manifest.json`，上限 **256 KiB**；不调用完整本地快照，不读取图片/字体，也不触发游戏目录配置 flush。
- 协议标识为 `scope: user-settings` / `cloud-settings-v1`。保留 v1 的四模块外壳便于兼容，`library` 和 `resources` 内容为空，`assets` 为空。全局设置按字段白名单投影，背景路径及启用状态仅留本机。
- 独立观察云端配置变化与版本号。游戏库、时长、壁纸和字体变化不排队请求；用户设置仍按两秒合并，沿用前台有限重试与 CAS 保护。
- 云端恢复只应用允许的设置和输入方案，保留本机游戏库、壁纸及字体。恢复日志记录 cloudOnly 标记，中断回滚及重启恢复遵循相同范围。
- 旧云备份只读取并校验 JSON 来提取用户设置，不下载资源文件。冲突继续保留双方；可安全迁移时发布小配置，旧资源按已有引用/十分钟下载 lease 规则在后续清理时回收。没有直接删除现有线上用户数据。
- 后端拒绝资源成员、超过上限的配置、非空游戏库/资源模块及背景路径。begin、upload、finalize 都执行范围检查，升级前已经开始的旧上传也不能继续存入资源。
- 保留旧版 head 的读取能力以迁移；已有大备份允许提交一次有界小配置来替换，避免因新容量上限而无法迁移。新配置的正常物理分块预算为每账号 768 KiB（另计 Base64、索引和记录）。
- 页面明确备份内容和大小上限，超限暂停并保留原备份，不进行反复重试。

## 验证

- 配置集成 **30 个场景通过**：包含 17 MB 字体不读取/不上传、游戏库等本地变化零云端事件、超限拒绝上传、旧大备份只读 JSON 迁移及过期清理、只恢复云配置时的中断回滚，并保留现有完整本地备份测试。
- 自动同步 **44 个场景通过**，购买/订阅 UI 及会员详情十五分钟虚拟时钟空闲检查通过。
- Linux Node 24 后端 **84/84** 通过，包含超限/资源/游戏库字段拒绝、旧 pending 拦截、原子发布与账号隔离。
- 隔离副本 CompileArkTS 通过；沿用已有 QA 处理，仅在副本排除无关 SmokeRunner 改动。完整原工作区包含其他功能的并发改动，未改写这些改动。
- 产物位于 `F:\VintagePomelo-Workspace\artifacts\user-configuration-only-20261019`，含测试日志、编译日志、源码标识和后端候选包。
