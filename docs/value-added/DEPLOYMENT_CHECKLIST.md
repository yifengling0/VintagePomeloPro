# 下一步需要你做什么

目前继续完成和验证代码，后台登录/部署按你的决定推迟。下面是部署前的顺序，不需要现在购买服务，也不要在聊天里发送密钥。

## 1. 只确认非秘密信息

- 已确认包名为 `com.vintage.pomelopro`，不改包名。
- 你已确认 AccountKit、云函数、CloudDB、IAP 已开通；复用现有服务，不重复新建。
- 在实际 Pro 应用详情中分别核对 App ID 和 OAuth Client ID。数字相似或截图处于 Client ID 栏，不等于能直接作为 IAP App ID 使用。
- 确认 tablet/PC 的正式分发签名方案和证书指纹。phone 支持和三平台构建配置继续保留。
- 提供现有后端是否已部署、非秘密 HTTPS 地址、项目/区域/应用对应关系的确认；如截图，请遮住所有 secret/AK/SK/私钥。

## 2. 决定隔离测试环境

代码目前是 Node >=22 的 HTTP 服务，且 IAP 验链需要 OpenSSL 3。要先核当前 AGC 云函数运行时、HTTP 事件适配方式、4 MiB 二进制请求及 base64 后大小上限、超时和成本预算，不能因“云函数已开通”就假定本包直接部署成功。

若现有函数不满足条件，先说明差异并决定调整分块/适配，不会自行购买新服务或换到其他数据库。

确认后才申请一次明确的测试部署操作，写清项目/区域/函数或容器/数据库 zone/对象桶、允许创建或更改的资源、预算和回滚方式。不会顺带正式上线或发布手机/PC 包。

## 3. 你在安全配置界面输入秘密

- Account Client Secret。
- IAP issuer/key ID、EC 私钥文件、官方 Huawei CBG Root CA G2 证书。
- AGC Server SDK 受保护凭据，独立身份 HMAC / 购买绑定 HMAC。
- OBS 最小权限部署凭据（如选用云档），专用私有桶和区域 endpoint。

这些内容只在官方后台或部署 secret/config 中输入，不发聊天，不放 Git、客户端 rawfile、构建日志或截图。配置长期凭据/权限时需要你明确确认并安全输入。

## 4. 明确商品

- 确认月卡采用非自动续订 type=3，期限为 `calendar-month-v1`（UTC 加一日历月、月末钳位）。若你要固定30天或自动续费，须在上架前改商品策略并补验收，不能卖出后默改。
- 确认月卡与支持开发 type=0 两个 SKU、实际价格/币种、商品说明。代码没有自行定价。
- 配置测试环境 `SANDBOX`；沙盒证据不能解锁 `NORMAL` 正式销售。

## 5. 按顺序验收

1. 配置 CloudDB 对象类型/仅服务端权限/首次哨兵，执行真正并发、服务端拒绝原子性和断网闭锁探针。
2. 真实 Account 授权码换取可信身份；不保存 provider refresh token。
3. 经授权的沙盒测试订单：验签、最新查单、幂等、finish 重试、退款和恢复；付款动作另行确认。
4. 如启用云档，先验证专用私有 OBS 桶，再运行几十字节的 checksum/读回/删除探针；不使用玩家存档。
5. 真机 tablet/PC 登录、购买、恢复、配置冲突、云存档跨设备手动绑定、下载/备份恢复；phone 新入口隐藏但原功能继续可用。
6. 完整 native/HAP 构建、签名和安装验证。ArkTS 编译通过不是完整包已能安装。

## 当前你不必做

不必重新开通你已经启用的服务、不必购买套餐、不必把任何密钥发给我。等你方便登录后台时，先做第1步的应用信息和运行环境核对即可。
