# 撤下存档备份与输入方案验证

日期：2026-10-13。分支：`feature/account-cloud-membership-mvp`，版本：`1.4.7 / 1004070`。此次仅交付开发测试包，不正式发布。

## 撤下范围

- 移除游戏设置中的存档识别提示、自动备份开关和管理入口，删除仅服务该入口的 `GameBackupSetting` 组件。
- 移除账号与同步中的本地存档、云端存档、恢复与目录绑定界面，以及相关状态、监听和服务调用。
- 首页不再初始化 `LocalSaveSnapshotService`，目录扫描不再调用其 `reconcileCatalog`。因此启动、目录刷新和 Wine 引擎退出均不再触发自动存档扫描、备份或迁移。
- 存档服务与领域模型暂时保留为后续设计参考，没有页面或应用生命周期调用。设备已有游戏存档、备份快照与事务文件不删除、不迁移、不清理。
- 会员区当前展示设置备份、输入方案备份，并增加“更多会员功能正在开发中”。两套皮肤共用该组件。

撤下原因：现有存档识别和整目录模型不能可靠处理游戏根目录中的散落文件、Wine 用户目录中的数据或多个存档位置。部分大型目录还会触发扫描预算限制。此次没有通过追加游戏白名单或放宽扩展名宣称修复通用识别。

## 输入方案修改与加载

通过正常 UI 创建独立测试方案，在布局编辑器新增一个按钮，将绑定改为 B（evdev 48）、形状改为方形、开启按住锁定并移动位置，点击正常保存。读取应用保存的方案确认这些修改实际落盘。

停止并重新启动应用后，逐字段比较完整方案，所有内容一致；再次打开真实布局编辑器，按钮位置、B 键绑定、方形选中及按住锁定均正确显示。原有五个方案内容始终不变。最后使用正常 UI 恢复默认方案并删除独立测试方案，读回核对用户方案及默认选择与测试前一致。

**本次完整云端往返未通过验收：**登录后的官方最新订阅状态为 `subscriptionStatus=2`、`status=expired`，应用正确显示会员已到期、云备份已暂停。没有伪造会员或重新确认付款，也没有修改玩家方案来绕过权益限制。真实 CloudDB 只读检查确认原有五个方案和设置备份仍与设备 journal 的 revision、SHA-256 一致，但这不证明本次修改上传或本地缺失后的云恢复成功。

本次未卸载应用、清数据、修改玩家游戏存档或确认新的订阅。修改后的方案真机云上传/恢复仍待有效测试权益下补测。
